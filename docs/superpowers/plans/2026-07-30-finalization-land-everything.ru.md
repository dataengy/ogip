# Финализация — приземлить всё, три зелёные run-команды, dev→main (2026-07-30)

Движущая цель: быстро привести репозиторий в презентабельное, готовое к релизу состояние.
Зонтичная задача: [.ai/tasks/finalization.md](../../../.ai/tasks/finalization.md). Режим:
**AUTO** (директива владельца) — фазы идут без пофазных ворот одобрения; чекпоинты
сообщаются после B/C/D, без ожидания подтверждения. Ограждения без изменений: никогда не
делать force-push в `dev`/`main`; никогда не коммитить файлы соседнего lane; удаление веток —
только после доказательства вхождения (containment); запасные выходы на двух рискованных
влитиях остаются в силе.

## Целевое состояние («готово»)

1. Три зелёные команды на сэмпл-данных: `make run-dbt`, `make run-bruin`,
   `make run-dagster-dbt` (Prefect + dbt-под-Dagster — уже реализовано как профиль
   `prefect-over-dagster`; нужен алиас + проверенный запуск).
2. Re-root ([#40](https://github.com/dataengy/ogip/issues/40)) T4–T9 завершены: dbt+bruin
   как основные в config/Makefile/гейтах/AGENTS.md + ADR-0020.
3. Каждый lane влит или громко заморожен: dagster [#34](https://github.com/dataengy/ogip/pull/34),
   odos [#37](https://github.com/dataengy/ogip/issues/37); ветки-заглушки удалены.
4. DQ-мониторы либо реально выполняются (ненулевой код при сбое), либо громко отложены —
   никакого тихого зелёного.
5. PR [#10](https://github.com/dataengy/ogip/pull/10) `dev → main` влит, CI зелёный.
6. Демонстрационная презентация (внешний репозиторий deck-generator) + черновики
   аутрич-писем — контент вне репозитория.

Уровни: **V1** питч-минимум (A, B, E) ≈ 1.5–2 дн. · **V3** += C (re-root влит) ·
**V4** += D (всё влито, main готов к релизу) · **V2** = V4 + реальное DQ-расписание + все
источники + живой R2 + реальный деплой на VPS (для витрины не требуется).
