# Кандидаты на скрейпинг после того, как реестр scrape-tier достроен

- **Дата:** 2026-07-23 · **Refs:** OGIP#18, OGIP#19
- **Контекст:** все четыре источника scrape-tier (`metacritic`, `opencritic`, `psn`,
  `steamcharts`) уже реализованы (`ingestion/sources/*.py`, не заглушки, с raw+staging
  моделями). Скрейпер `psn` дорабатывается в параллельной сессии. Так что «лучший кандидат на
  скрейпинг» — это больше не «что строить первым», а «что дальше, и скрейпинг ли это вообще».

## Ранжирование по ценность × легальность × осуществимость

Перечитывание домена (`.ai/newsletter.hushcrasher.com/SUMMARY.md`) фиксирует ось ценности: две
решающие переменные модели — это **длина credits** (MobyGames) и **размер диска / длина
прохождения** (HowLongToBeat).

| Кандидат | Доменная ценность | Вердикт |
|---|---|---|
| **MobyGames** — credits | 🔴 наивысшая (драйвер модели #1) | **Заблокировано** — ToS. См. ниже. |
| **HowLongToBeat** — время прохождения | 🔴 наивысшая (драйвер #2) | **Заблокировано** — ToS. |
| **Gamalytic** — выручка | 🟠 высокая; названный источник, отсутствовал | **Не скрейпинг — API без ключа.** См. ниже. |
| SteamCharts (готово) | — | лучший образец: единственный настоящий CSS-селекторный скрейп в реестре |

## Заблокированная находка — заявите её, не прячьте

Две переменные, которые сильнее всего управляют моделью scope/budget у Hushcrasher, приходят из
**MobyGames** (credits) и **HowLongToBeat** (длина). Обе заблокированы для использования OGIP
по ToS ([[ogip-business-domain-framing]]). Поэтому:

> OGIP может воспроизвести *дешёвую* половину таксономии scope (размер диска, число языков —
> обе достижимы из Steam) и **ни одной из дорогой половины** (credits, курируемое время
> прохождения). Это правовое ограничение, а не инженерный пробел, и оно ограничивает,
> насколько близко платформа может зеркалить эталонную модель. Это принадлежит документу об
> ограничениях платформы, заявленное прямо, наперёд.

Здесь нет никакой хитрости скрейпинга, которая это исправит — должен появиться допустимый
источник, иначе переменная остаётся вне модели.

## Gamalytic — это API, а не скрейп

Проверено вживую 2026-07-23:

- `api.gamalytic.com/steam-games/list?page=0&limit=1` → **HTTP 200, без ключа**,
  `pages: 124522`, каждая строка несёт `copiesSold` (прокси выручки). С пагинацией — ровно
  форма dlt `rest_api`.
- `api.gamalytic.com/game/{id}` → **403**, «requires an API key … upgrade to Starter or
  Professional». Детальные данные по каждой игре — платные.
- `gamalytic.com/robots.txt` → **429 + Vercel Security Checkpoint** (сайт анти-бот; хост API —
  нет).

Так что наивысший по ценности *допустимый* пробел маршрутизируется на **dlt, tier `direct`,
`auth: none` для list-эндпоинта** — а не на скрейпер. Это единственная лучшая следующая цель
ингестии, и это не скрейпинг.

## Рекомендация

1. **Новый скрейпер не оправдан.** Хвост скрейпинга достроен; параллельная сессия его
   завершает.
2. **Gamalytic → dlt-дескриптор** (lane ингестии, передано с доказательствами проб выше).
3. **Задокументировать блок MobyGames/HLTB** в документе об ограничениях платформы — честный
   потолок точности воспроизведения эталонной модели.
