# `ingestion/samples/` — демо-фикстуры (СИНТЕТИКА)

Небольшие, **написанные вручную** образцы payload'ов, чтобы пайплайн проходил end-to-end с
**нулём учётных данных** (демо-режим / CI). Это **не** сохранённые ответы API.

| Файл | Происхождение |
|---|---|
| `rawg_games.json` | Синтетика. Реальные названия игр + реальные RAWG ID, форма как у RAWG `/api/games`, но значения метрик (`rating`, `ratings_count`, `added`, местами `metacritic`) — **приближения**, а не реальная выгрузка. |
| `metacritic_game.html` | Синтетика. Каркас страницы реальной ФОРМЫ со schema.org `VideoGame` JSON-LD, сверенным зондом с живой страницей 2026-07-18 (Hades, metascore 93, 61 рецензия). Два блока `ld+json` намеренно — парсеры должны выбирать по `@type`. |

**Инжест по-прежнему делает dlt** — в демо-режиме dlt загружает *эти записи*; в live-режиме
dlt загружает записи, полученные из реального API. Чтобы вместо этого захватить **реальный**
образец, задайте RAWG API key в `.env` и выполните `just capture-sample rawg` (тянет живые
данные через dlt и перезаписывает фикстуру).

**Правило размера (Git LFS):** маленькие текстовые фикстуры (как `rawg_games.json`) остаются в
обычном git — они диффабельны и удобны для ревью. Бинарные/большие образцы (`*.parquet`,
`*.zip`, `*.gz`) автоматически идут через **Git LFS** по `.gitattributes`; выполните
`make lfs-install` один раз на клон, иначе `git add` молча сохранит сырой blob, а
`.ci/run.sh lfs-guard` завалит сборку.
