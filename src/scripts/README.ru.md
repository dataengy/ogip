# `src/scripts/` — долговременные служебные скрипты

Переиспользуемые dev/ops-скрипты, вызываемые из Makefile/Justfile (например, `run-profile.py`).
Долговременные, отслеживаемые в git, покрытые тестами — в отличие от черновых скриптов в `.tmp/`.
Целевое место «выпуска» для проверенных скриптов из `.tmp/`.
