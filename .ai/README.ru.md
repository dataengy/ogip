# `.ai/` — agentic-хаб

Хаб-точка входа для AI-агентов и людей, работающих над OGIP. Корневой `AGENTS.md` — симлинк сюда.

| Файл / директория | Назначение |
|---|---|
| [AGENTS.md](AGENTS.md) | **Начинайте отсюда.** Общие правила, жёсткие правила, конвенции, профили запуска. |
| [CLAUDE.md](CLAUDE.md) | Заметки о рабочем процессе Claude Code (команды, гейты). Корневой `.claude/CLAUDE.md` — симлинк сюда. |
| [PLAN.md](PLAN.md) | Мастер-план создания — целевой дизайн + пофазная сборка + зафиксированные решения. |
| [TODO.md](TODO.md) | Короткие упорядоченные чекбоксы ближайших действий; ссылается на задачи/фазы. |
| [FIXME.md](FIXME.md) | **Известные конфликты и долг, высокий приоритет** — противоречия документов, пробелы конвенций, то, через что нельзя молча переступать. |
| [STATUS.md](STATUS.md) | Живой статус: текущая фаза, последнее сделанное, следующие шаги, журнал решений. |
| [SKILLS.md](SKILLS.md) | **Какие агентские скиллы здесь применимы** — и ~193 каталожных скилла, нацеленных на инфраструктуру, которой у OGIP нет (Jira, GitLab, ClickHouse, SSH-парк). Читайте, прежде чем тянуться за скиллом. |
| [tasks/](tasks/) | Пофазные и разовые task-файлы (рабочие заметки, чек-листы). |

Конвенция: долговечные правила → `AGENTS.md`; живое состояние → `STATUS.md`; ближайшие действия →
`TODO.md`; известные противоречия и долг → `FIXME.md`; дорожная карта → `PLAN.md` и
[../docs/ROADMAP.md](../docs/ROADMAP.md). Задачи синхронизируются с GitHub Issues/Projects через
`just tasks-sync`.
