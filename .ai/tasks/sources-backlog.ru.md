# Задача — Бэклог источников: кандидаты, сопоставленные моделям игрового рынка

**Статус:** 📋 бэклог (grooming) · **Приоритет:** P2

Источники-кандидаты для расширения покрытия, сопоставленные use case'ам рыночной аналитики,
которым служат выходные данные: **ценообразование · масштаб/длительность · производственный бюджет ·
трекшн/внимание · качество**. Каждый источник попадает в продакшен только по стандартному пути: контракт ODCS →
`BaseSource`/`ScraperSource` → landing/raw → spec-модели
([ADR-0006](../../docs/adr/ADR-0006-dlt-default-ingestion-postgres-landing.md) ·
[ADR-0014](../../docs/adr/ADR-0014-resilient-scraping-concurrency.md)).

## Выпущено

| Источник | Режим | Питает |
|---|---|---|
| RAWG | API (dlt-direct) | каркас каталога: игры, жанры, платформы, рейтинги (M0) |

## Правила grooming'а

- Продвижение кандидата = собственный файл задачи + черновик контракта ODCS + ревью ToS/robots
  (politeness из ADR-0014) + оценка трудозатрат (держит per-source-скоупинг честным).
- Предпочитать источники, открывающие **новое измерение модели** (цены, масштаб, бюджет, трекшн,
  качество), а не ещё-больше-тех-же метаданных.
- Список PLAN A6 (Steam · RAWG · IGDB · Reddit · Twitch · HLTB · Metacritic) остаётся
  зафиксированным ядром; строки 6 и 8–13 — расширения, ожидающие ревью объёма/ToS
  ([OPEN-QUESTIONS §1–§2](../../docs/OPEN-QUESTIONS.md)).
