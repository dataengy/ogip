# `.ai/tasks/`

Рабочие файлы задач OGIP — один файл на фазу или на разовую работу (чек-листы, заметки,
свидетельства приёмки). Долговременные правила живут в [../AGENTS.md](../AGENTS.md); дорожная карта —
в [../PLAN.md](../PLAN.md); актуальный статус — в [../STATUS.md](../STATUS.md).

Именование: `phase-<n>-<slug>.md` для списков задач фаз, `<yyyy-mm-dd>-<slug>.md` для разовых работ.
