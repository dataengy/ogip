# Задача — Демо интеграции Python-задач

**Статус:** ✅ демо выпущено; будущий адаптер SQL-transform-инструмента остаётся в планах.

## Сделано

- Добавлен `experimental/python_tasks/` с границами задач «dataframe на входе — dataframe на выходе».
- Добавлена pandas-задача над существующей структурой `core.game`:
  импутация числовых значений, лог-масштабированный сигнал rating/count, оценка критиков, перцентиль и
  метка популярности, пригодная для примера обучающей ML-выборки.
- Добавлена Polars-задача над вложенными жанрами `rawg__games`, дающая счётчики на уровне жанров.
- Добавлены unit-тесты на выходные признаки, дрейф контракта и опциональное выполнение на Polars.
- Задокументирована защита от утечки (leakage): продакшен-метки должны браться из будущего снапшота, а не
  из текущей/сервинговой строки признаков.

## Доказательства приёмки

- Ruff проходит для новой задачи и тестов.
- Unit-тесты проходят; тест Polars пропускается, когда опциональная зависимость Polars отсутствует.
- Ни дефолтный `make`, ни Prefect, ни SQLMesh, ни пути `spec/` не импортируют демо.

## Следующий шаг

Добавить тонкий адаптер SQL-transform-инструмента, который отображает реляционные входы на эти чистые функции и
сохраняет возвращённый ими dataframe, не перенося логику признаков в код оркестрации.
