# Задача — Агентная наблюдаемость: мониторинг агентов, строящих OGIP (standard-first)

**Статус:** 🚧 в работе — план утверждён 2026-07-19; Фаза 0 (OTel-спайк) в процессе.

Lane: `obs`. Объём: `deploy/obs/**`, `src/scripts/obs-*`, `.claude/settings.local.json`
(телеметрия по opt-in), документация. План: `~/.claude/plans/fable-xhigh-silly-melody.md`
(локальный для сессии).

## Зачем

Обс-стек следит за пайплайном; за **агентами**, которые его строят, не следит никто —
несколько параллельных сессий Claude Code жгут токены, запускают скиллы/сабагентов, держат
lane'ы и отгружают коммиты без единого дашборда и без трендового алертинга. Аудит каталога
скиллов подтвердил пробелы: нет аналитики токенов/стоимости, нет аналитики сабагентов, нет
трендовых алертов, нет дашбордов по работе в GitHub, нет поверхности Grafana ни для чего из этого.

**Постоянная директива: стандартные специализированные инструменты вместо самописного тулкита.**

## Подход (какой стандартный инструмент закрывает каждый запрос)

| Запрос | Стандартный инструмент |
|---|---|
| Алертинг по активности агентов | Нативный **OTel** Claude Code → Alloy (:4318, уже работает) → VM/Loki → **Grafana unified alerting** (провижининг как код) → **нативный Telegram contact point** |
| Дашборды статуса/прогресса сессий | Grafana по метрикам `claude_code_*` + OTLP-события в Loki |
| Эффективность токенов/скиллов/сабагентов | OTel-метрики (live) + **ccusage через npx** (история); скиллы уже покрыты `session-skills-digest.py` |
| Общее агентное здоровье | тот же дашборд Grafana (`ogip-agentic.json`); Evidence/Metabase сознательно НЕ используются |
| Работа с issues/projects GitHub | **GitHub Projects v2 + Insights**, ноль кода; `tasks_sync.py` без изменений |

## Фазы

0. **OTel-спайк** (гейтит всё остальное): сессия с env-префиксом → точные имена серий `claude_code_*` в VM;
   атрибуты событий; шум экспортёра при выключенном стеке. Запасной вариант: только ccusage, без кастомного коллектора.
1. Alloy: маршрутизация OTLP-**логов** → Loki (метки: только `service.name` + `event.name`).
2. Провижининг алертинга Grafana (contact-points/policies/5 правил) + **выделенный TG-чат**
   (интерактивный онбординг, креды через существующий флоу add-secret; интерполяция `$VAR` — без
   секретов в YAML). Переиспользует идею webhook-ресивера из задачи obs-alerting-tail:
   нативная доставка Grafana заменяет кастомный ресивер; внутрипроцессный `Notifier` остаётся
   для хуков Prefect.
3. Дашборд `ogip-agentic.json` (сессии/прогресс · эффективность, включая таблицу тулов
   `Agent|Skill` · здоровье).
4. Включение: env-блок в `.claude/settings.local.json` (продвижение в общие настройки — через
   задачу координации сессий), `just agentic-usage` (ccusage), документация, апсерт глоссария.
5. GitHub Projects v2 + Insights (нужен `gh auth refresh -s project,read:project`).
6. Бухгалтерия. Регрессия flow-хука после рефакторинга engines/: ✅ проверено — хук переехал
   в общую фабрику флоу (`pipelines/flows/_common.py`), все engine-флоу его несут.

## Сознательно не строим

Кастомный webhook-ресивер · кастомные JSONL-коллекторы/парсеры · Evidence/Metabase · новые
скиллы уведомлений. Каждый пункт закрыт стандартным инструментом выше.
